# Kampüs Etkinlikleri

Kampüste düzenlenen etkinlikleri listelemek, detaylarını göstermek ve yeni etkinlik eklemek için hazırlanmış bir web projesidir.

**Hazırlayan:** Hayrunnisa Altınkaya - 2416501087

**Canlı site:** https://hayrunnisa64.github.io/kampus-etkinlik/sprint1/

## Sprint 1

Bu sprintte sadece HTML kullanılmıştır. CSS ve JavaScript yoktur.

| Sayfa | İçerik |
| --- | --- |
| `index.html` | Uygulamanın amacı, etkinlik listesi (her etkinlik bir hücrede) ve Ayın Programı tablosu |
| `etkinlik-detay.html` | Etkinlik afişi, künye bilgileri (tarih, yer, kategori, kontenjan) ve ayrıntılı açıklama |
| `etkinlik-ekle.html` | Yeni etkinlik ekleme formu |
| `etkinlik-guncelle.html` | Bilgileri dolu gelen etkinlik güncelleme formu |
